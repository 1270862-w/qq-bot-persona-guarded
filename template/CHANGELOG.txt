========================================================================
QQ 群机器人 · 开发日志
========================================================================
内部测试线：1.0 → 1.12.4（所有问题与修复都在这里）
公开版：    2.0.0（等于 1.12.4 的快照，未做任何更改）
生成日期：  2026-02-04

记录方式：每个版本写三件事——发现了什么问题、改了什么、结果如何。
早期版本按功能节点归档编号；1.11 之后为真实运行中暴露的问题。
========================================================================


------------------------------------------------------------------------
1.0.0  基础骨架
------------------------------------------------------------------------
[问题] 需要一个能收发群消息的机器人，不处理 QQ 登录。
[改动] 接 OneBot v11（WS + HTTP）；实现消息解析、去重、四层节流
       （全局间隔 / 单群冷却 / 每小时上限 / 每日上限）、同群串行。
[结果] 能稳定收发；重复消息不重复回；并发不会穿透节流。

------------------------------------------------------------------------
1.1.0  人格文件
------------------------------------------------------------------------
[问题] 人格写死在代码里，改一句要动代码。
[改动] 引入 persona.md：一个文件装默认人格 + 多个彩蛋人格；
       支持 nick / alias / trigger / reset / 切换台词 / 退场台词。
[结果] 改人格只需编辑文本，不用碰代码；格式错误有告警。

------------------------------------------------------------------------
1.2.0  识图
------------------------------------------------------------------------
[问题] 群里发图，机器人当没看见。
[改动] 解析 image 段，把图片交给多模态模型描述；支持多张图。
[结果] 能描述图片内容；图片没有 url 时会明确报错。

------------------------------------------------------------------------
1.3.0  长期记忆
------------------------------------------------------------------------
[问题] 聊过的事转头就忘，每次都要重新自我介绍。
[改动] 每群一个记忆文件；记录成员与事实；按话题召回（bigram +
       同义词别名），容量 120，召回 10 条注入 prompt。
[结果] 能记住群内约定；召回按相关度排序，不再一股脑塞进去。

------------------------------------------------------------------------
1.4.0  能力边界与政治拦截
------------------------------------------------------------------------
[问题] 有人让它写代码、查报错；也有人抛政治话题。
[改动] 能力边界：关键词 + 请求语气 + 吐槽词三层判断，命中则拒绝，
       拒绝话术按人格分派；政治话题：繁简归一 + 符号剥离后匹配，
       只拒绝、不表态。
[结果] 开发请求被挡；政治话题不接话；拒绝仍符合人格口吻。

------------------------------------------------------------------------
1.5.0  话题嗅觉与作息
------------------------------------------------------------------------
[问题] 群里冷场时它一声不吭；半夜还在说话。
[改动] 冷场主动开话题、聊天中伺机插话（按群统计节奏）；
       作息：到点晚安/早安，静默时段不响应；公告当天只发一次。
[结果] 冷场有反应；半夜不再吵；公告不重复。

------------------------------------------------------------------------
1.6.0  联网搜索
------------------------------------------------------------------------
[问题] 问新闻、价格、时效信息时答不上来或编造。
[改动] 接搜索 API，做成 function calling，模型自行决定是否搜索。
[结果] 时效问题能查到；闲聊不触发搜索，成本可控。

------------------------------------------------------------------------
1.7.0  彩蛋人格
------------------------------------------------------------------------
[问题] 用户想要"触发词切人格"的玩法。
[改动] 支持触发词切换、恢复词切回、自动到期；切换有每小时次数限制；
       彩蛋最多 4 个。
[结果] 切换稳定；不会因为重复触发反复播报。

------------------------------------------------------------------------
1.8.0  投递模式与自愈
------------------------------------------------------------------------
[问题] 想先观察再放量；网络断了要手动重启。
[改动] 三种模式：dry（只看不发）/ manual（进队列等批）/ auto（直接发）；
       心跳检测 + 半开连接自愈，连续失败自动重连。
[结果] 可安全灰度；断线能自己恢复。

------------------------------------------------------------------------
1.9.0  安全加固
------------------------------------------------------------------------
[问题] 记忆可能被"记住：以后你都…"这类话污染；
       拒绝时可能被诱导输出代码。
[改动] 记忆入库前过滤指令式内容；拒绝路径检查是否含代码，
       含代码直接丢弃；所有发言收敛到单一出口 _emit。
[结果] 记忆投毒被挡；拒绝不会夹带代码；新功能无法绕过净化。

------------------------------------------------------------------------
1.10.0  工程化
------------------------------------------------------------------------
[问题] 三个版本靠手工同步，改一处要改三遍，容易漏。
[改动] 单源构建：lib / tests / variants → build.mjs 生成三个包并校验
       一致性；release.sh 打包；补测试套件、覆盖率、变异测试。
[结果] 三个包共享文件字节一致；一处修改三处生效。

------------------------------------------------------------------------
1.11.0  真机第一轮：从"必须@"到"会看场合"
------------------------------------------------------------------------
[问题] 真机上必须 @ 才说话；不 @ 就不理；随机概率又低到像没有。
[改动] 引入"临时日志"（每群最近若干条消息）；触发改为打分制
       （呼叫词、问号、疑问词、「你」、请求词、接话、纯附和扣分）；
       删除随机概率；emoji 转文字；纯表情不触发。
[结果] 不 @ 也能接话；不再赌概率；表情消息不再被当成空消息。

------------------------------------------------------------------------
1.12.0  群隔离
------------------------------------------------------------------------
[问题] 一个群触发彩蛋，所有群都变人格；两个插件实例记忆互相串。
[改动] 彩蛋状态按群隔离（activeId / 剩余时间 / 残留记忆各自独立）；
       记忆目录改为 memory/<实例>/<群号>/memory.json，旧文件自动迁移。
[结果] A 群触发不影响 B 群；不同实例互不可见。

------------------------------------------------------------------------
1.12.1  人格持久性
------------------------------------------------------------------------
[问题] 多人聊天里人格很容易掉回默认：群友闲聊里带出恢复词就重置；
       30 分钟到期；被叫到也不续期。
[改动] 恢复词只在 @ / 提到名字 / 整句 ≤8 字时生效；时长 30 → 60 分钟；
       被叫到时自动续期；新增 anchor 字段，每轮提醒人格后段规则。
[结果] 闲聊不会打回默认；活跃对话不过期；长对话口吻衰减变慢。

------------------------------------------------------------------------
1.12.2  识图收敛
------------------------------------------------------------------------
[问题] 识图太勤：纯刷图也认；同一张图反复认；重复内容反复记录。
[改动] 纯图不认，配文字或有上下文才看；单群冷却 20 秒；
       按 file 指纹去重，90 秒内不重复识别；
       图片档案：同图出现 3 次自动拉黑，之后永不回，记录写入
       memory/<实例>/blocked-images/。
[结果] 不再见图就答；重复图只处理一次；高频刷图被永久忽略。

------------------------------------------------------------------------
1.12.3  说话人识别
------------------------------------------------------------------------
[问题] @ 了别人、句中有「你」，它也会抢话；回话时不知道是谁在说。
[改动] 解析并保留 @ 目标；@ 的是别人时整条不参与判断，
       「你」不计分；送模型的文本带上说话人名称。
[结果] @ 别人不再误触发；回复能对上具体群友。

------------------------------------------------------------------------
1.12.4  降活跃 + 强制人格格式（当前内部版）
------------------------------------------------------------------------
[问题] 阈值 3 时什么都接话；触发太随机；人格该带的格式会忘。
[改动] 阈值 3 → 10，权重重标；分区判断：普通消息攒 20 条整批看一次，
       @ / 叫名字 / 直接请求 / 呼叫词（必须带当前人格名字）才立即回；
       彩蛋期间必须用彩蛋自己的名字；人格可声明 requirePattern，
       代码检查、重试、兜底（逻辑必须带「……　// 修正：」）；
       回话率分级：小鲸鱼 9 / 长征酱 9 / 逻辑 13；
       触发词每人格保留 2 个；彩蛋上限 3 次/小时。
[结果] 真实模型语义测试 13/13 符合预期；固定格式 100% 出现；
       普通闲聊不再逐句插嘴。

1.12.5  插件体系与搜索补全
========================================================================
[问题] 功能只能改主包；没有扩展机制；搜索学习无处安放。
[改动] 插件宿主（emit.use / prompt.use / on message），热加载；
       加载前三道门：握手、人格文件存在、含 webSearch 字段；
       人格新增 webSearch 与 searchKeyword；
       独立插件 search-learn：按群隔离搜索、来源打分、双来源才下结论。
[结果] 搜索知识按群存放，插件无法直接发消息，输出仍走 _emit。
