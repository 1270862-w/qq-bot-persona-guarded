## 尺寸与排版

- 原始截图是手机竖屏（约 1080×1200 ~ 1080×3300），直接插入会非常长
- 文档里用 `<img width="430">` 控制宽度，GitHub 上渲染约 430px 宽
- 如果想让页面更紧凑，建议把每张图**裁到对话区域**，去掉顶部标题栏和底部输入框
